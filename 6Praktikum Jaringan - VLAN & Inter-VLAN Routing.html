Konfigurasi Sub-Interface (ROAS)

Target GW: 192.168.10.1 (VLAN10), 192.168.20.1 (VLAN20), 192.168.30.1 (VLAN30). DHCP Server diaktifkan otomatis.

Core Switch L3

Konfigurasi jalur distribusi 802.1Q (Trunk) antar perangkat layer distribusi.

Switch Lantai 1

Atur VLAN ID sesuai peruntukan PC. Pastikan port uplink diset Trunk.

Switch Lantai 2

Atur VLAN ID untuk Lantai 2.

Konfigurasi PC

Gunakan fitur DHCP untuk merequest IP secara otomatis dari Router, pastikan Trunk dan Access port sudah dikonfigurasi dengan benar agar Broadcast DHCP sampai ke Router.
