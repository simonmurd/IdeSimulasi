Materi & Evaluasi Lab
1. HSRP / VRRP (Virtual IP)
30 Poin
Pengujian failover otomatis saat Router Main dimatikan. Target VIP: 192.168.1.254, R-Main Priority > 100.
2. EtherChannel (LACP)
20 Poin
Menggabungkan 2 kabel fisik antar-switch (Core 1 & 2) untuk menambah bandwidth menggunakan LACP.
3. Spanning Tree Protocol (STP)
30 Poin
Mencegah network loop pada jalur fisik yang melingkar. Aktifkan STP pada Switch Access dan set Root Primary di Core 1.
4. Konfigurasi Gateway Client
20 Poin
Client harus mengarah ke Virtual IP HSRP (192.168.1.254) agar tetap terhubung saat failover.
